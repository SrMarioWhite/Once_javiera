# Requerimientos de Software
## abstracción:
Capacidad intelectual mediante la cual la mente aísla las características esenciales de un objeto o situación, ignorando los detalles secundarios.

## Niveles de abstracción:

- Especificación técnica: La API /menu/dia debe retornar un JSON con los platos del día, en menos de 300 ms, usando HTTPS.

- Requerimiento del sistema: El sistema debe mostrar el menú del día actualizado a todos los estudiantes autenticados.

- Necesidad del usuario: Quiero saber qué hay de comida para no perder el viaje a la cafetería.
